# Customer Segmentation Using RFM Analysis & K-Means Clustering

An unsupervised machine learning project developed as part of the **Oasis Infobyte Data Analytics Internship (Level 1, Task 2)**. This project segments a customer base by evaluating purchasing behavior using **RFM (Recency, Frequency, Monetary)** analysis combined with **K-Means Clustering**[cite: 2].

---

## 📌 Project Overview
Understanding customer behavior is essential for targeted marketing, personalized campaigns, and optimizing retention strategies[cite: 2]. This project processes a transactional retail dataset to[cite: 2]:
1. Clean and preprocess raw transaction logs[cite: 2].
2. Engineer **RFM (Recency, Frequency, Monetary)** metrics for individual customers[cite: 2].
3. Apply feature scaling and determine the optimal number of clusters using the **Elbow Method**[cite: 2].
4. Train a **K-Means Clustering** model to group customers into distinct behavioral segments[cite: 2].
5. Profile and visualize the resulting customer segments[cite: 2].

## 📂 Workflow & Methodology

### 1. Data Cleaning & Preprocessing
* Removed rows with missing `CustomerID`s to ensure accurate user-level aggregation[cite: 2].
* Filtered out canceled orders, returns, and anomalous records where `Quantity <= 0` or `UnitPrice <= 0`[cite: 2].
* Calculated total purchase value (`TotalPrice = Quantity * UnitPrice`) for each transaction line item[cite: 2].

### 2. RFM Feature Engineering
For each unique customer, three core metrics were calculated[cite: 2]:
* **Recency (R):** Number of days elapsed since the customer's last purchase (relative to a reference snapshot date)[cite: 2].
* **Frequency (F):** Total number of distinct transactions/invoices made by the customer[cite: 2].
* **Monetary (M):** Total cumulative financial spend generated by the customer[cite: 2].

### 3. Clustering Pipeline
* **Scaling:** Normalized the RFM feature matrix using `StandardScaler` to bring all variables to a comparable scale (mean = 0, variance = 1)[cite: 2].
* **Elbow Method:** Evaluated Within-Cluster Sum of Squares (Inertia) across values of $K$ (from 1 to 10) to identify the optimal cluster count[cite: 2].
* **Model Training:** Fitted the K-Means algorithm to segment customers into actionable tiers (e.g., Champions, Loyal, At-Risk, Dormant)[cite: 2].
